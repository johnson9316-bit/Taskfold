## 当前交接

项目名称为 **`taskfold`**。它是一个 OpenClaw 插件，插件 ID 和显示名称均为 `taskfold`；不再开发独立 Web 应用、`taskfold serve` 或插件外运行时。

M1 的唯一目标是完整复制 OpenClaw 官方 Workboard 功能层，保持其代码结构、插件规范和开发风格，只完成 taskfold 的命名、manifest、打包、许可证记录和安装资料。

本机 OpenClaw 已验证版本为 `2026.7.1-2`，标准安装方式为：

```bash
# 本地开发
openclaw plugins install --link <本地-taskfold-目录>

# Git 仓库分发
openclaw plugins install <Git-仓库地址>
```

M1 完成前必须在本机执行：

```bash
openclaw plugins inspect taskfold --runtime
openclaw plugins doctor
```

并从干净 clone 重复 Git 安装和 Workboard 看板冒烟测试。

## 已定

1. 技术栈：TypeScript + Node。
2. 代码基线：OpenClaw Workboard 的固定上游快照；保留 MIT 署名、上游 commit 和本地改动记录。
3. 分发：提交 Git 仓库；安装方式使用 OpenClaw 标准 `plugins install`。
4. M1 不做 GSD `.planning/`、GSD 专属 ACP 执行调度、MCP、AI、独立服务或新看板设计；复制的 Workboard 原有功能保持不变。
5. M2 先完成多项目、项目设置和项目资料，需求见 [[8.2-需求]]、实施计划见 [[8.2-看板通用功能plan]]；M4 才开始 GSD 投影和 OpenClaw ACP Runtime 执行调度，默认单 repo、单隔离 worktree、单 active run。
