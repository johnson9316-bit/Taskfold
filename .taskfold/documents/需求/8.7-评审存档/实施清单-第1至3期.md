# 8.7 实施清单索引

> 执行顺序固定为第 1 期 -> 第 2 期 -> 第 3 期。每一期达到其完成门槛并留下验证证据后，
> 才能进入下一期。

| 顺序 | 文档 | 交付目标 |
| --- | --- | --- |
| 第 1 期 | [单 Card ACP 闭环](实施-第1期-单Card-ACP闭环.md) | Claude 的启动、人工计划审批、执行、同步、取消和 `review` 闭环。 |
| 第 2 期 | [人工出口与 Git 安全](实施-第2期-人工出口与Git安全.md) | worktree/Git 治理、合并/PR/丢弃、退回修改和 unknown 恢复。 |
| 第 3 期 | [受控并发与 writeScope](实施-第3期-受控并发与writeScope.md) | writeScope、并发槽、项目/仓库上限和预算账本。 |

所有阶段的前置条件：官方 ACP Spike 已留下可复现证据；`@openclaw/acpx` 的 `doctor()` 成功，
Claude harness 可由公开 ACP API 创建、执行、查询、取消、关闭，并能在重启后按 `sessionKey`
对账。未通过时停止，不回退到 Bridge 或第三方 `openclaw-code-agent`。
